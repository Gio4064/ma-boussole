# Ma Boussole

Application web installable (PWA) de bilan de confiance en soi et d'orientation vers des professionnels de santé mentale.

## Mettre en ligne sur Netlify Drop
1. Aller sur https://app.netlify.com/drop
2. Glisser-déposer tout le DOSSIER "boussole" (pas juste index.html) dans la zone.
3. Le site est en ligne en quelques secondes, avec une adresse du type nom-au-hasard.netlify.app

## Mettre à jour
Pour voir une nouvelle version, re-glissez le dossier mis à jour sur la même page Netlify Drop : ça remplace le site en quelques secondes.

## Confidentialité
Aucune donnée n'est envoyée à un serveur. Le compte et l'historique sont stockés dans le navigateur de la personne (localStorage) et supprimables depuis l'onglet Compte.

## Limites
Outil indicatif, sans diagnostic. Pas de vrai compte multi-appareils : il faudrait un serveur (FastAPI + MongoDB) et un hébergeur certifié HDS pour les données de santé.
